# Brand logo

Drop the Zyberworks logo file here as `logo.png` (or `logo.svg`, preferred if available — crisper at all sizes) to replace the built-in inline icon used in the nav bar and footer.

The site falls back to a simple inline SVG mark until this file exists, so nothing breaks in the meantime. Once `logo.png` or `logo.svg` is added and pushed, it's picked up automatically — no code changes needed.

Recommended: a square or near-square image, transparent background, at least 256×256px.
